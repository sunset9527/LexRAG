# Stage 5 自动选库与跨库证据编排核验记录

核验日期：2026-10-25

## 已实现

- `/query` 支持空知识库范围的规则型自动路由，以及显式单库或多库范围；低置信度返回结构化候选，前端可点击候选后以显式范围重问。
- 自动路由只从当前组织可见、`READY` 的法规库选择；显式范围优先。
- 每个选中库独立解析案件日期对应的 Stage 4 版本 collection，并由独立检索器查询。
- Evidence Ledger 保留知识库边界；引用校验支持本轮多个法规库，且逐条引用回传来源库和版本溯源字段。
- HyDE 由 `hyde_enabled` 控制，默认关闭时不会调用生成。
- LangGraph 增加 `knowledge_base_routing` 节点，并在安全工作流 trace 中输出已选择库数量。
- 无改写或改写降级时的主检索入口也优先走 BM25 + 向量 RRF；多候选 Query Rewrite 的每一路复用混合检索，再以 RRF 融合候选。向量 distance 在兼容分支转换为“高分更相关”，所有结果标记 `score_type`、方向与 `[0,1]` 归一化分数。
- 法律术语别名以可审计规则扩展（例如“虚构事实、隐瞒真相、骗取”补充“诈骗罪”），不绑定或硬编码任何法条答案；第 `X` 条之一的解析、引用校验和评测 ID 已统一。
- 图谱扩展固定一跳，并只保留与种子法条同一法律的节点；案例与法规仍为独立证据类型和排序路径。
- 问答页面默认自动选择，支持多选、实际使用库展示、低置信度候选重问，以及引用卡片的来源库、版本、生效日期和官方 URL。
