# LexRAG v2.2 法律场景工作流设计

## 目标与边界

v2.2 将通用问答扩展为五个可追溯场景：合同审查、合规检查、法律文书生成、维权路径规划与法律报告。所有法律结论只能基于当前请求的证据账本中的法条；系统提供法律信息参考，不构成法律建议。

本版本复用已有 PDF/DOCX 异步解析、法规知识库、案例库、v2.1 证据账本与引用校验。不会引入外部法规数据，也不会把自动化测试结果描述为真实 LLM 效果。

## 架构

新增 `legal_scenarios` 领域层，提供纯函数规则引擎和可注入的生成器。新增场景任务记录，状态为 `PENDING -> PROCESSING -> READY | FAILED`，每项任务由已上传的源文档或结构化表单驱动。Worker 执行耗时的文档场景；维权路径和文书草稿同步生成。

场景结果以统一 JSON 保存：输入摘要、条款或检查项、风险等级、原文位置、证据、已校验引用、建议、降级原因与免责声明。报告服务只消费该结构化结果并生成 PDF，因此不重新推理或新增法律结论。

## 五个工作流

1. 合同审查：按标题、条号和段落切分条款；规则定位违约责任、免责、格式条款和争议解决风险。每个命中项以条款文字作为检索问题，只有取得法条证据时才可输出法律依据；否则标为“需人工核验”。
2. 合规检查：输入制度或合同，选择劳动或公司领域。规则检查常见高风险措辞，逐项返回 `pass`、`review` 或 `risk`，并附证据状态。
3. 文书生成：五个白名单模板定义必填字段。缺失字段返回校验错误；生成器只使用提交字段、模板和证据生成草稿，不补造事实。
4. 维权路径：内置劳动、合同、侵权三类受控路径。节点含条件、材料、行动与提示；法条支撑不足时将节点标记为人工核验。
5. 法律报告：选择一个或多个已完成场景任务，生成可读 HTML/PDF。报告清晰显示风险等级、条款位置、引用、未验证项和免责声明。

## 安全与降级

任务按 JWT 用户 ID 过滤；未登录或访问他人任务返回拒绝。文件与场景输出不在响应中泄露其他用户信息。LLM、向量检索或 PDF 导出失败时记录无敏感内容的失败原因；不会产生伪造引文或“已审查完成”的结论。

## API 与前端

`/scenarios` 提供创建、列表、详情、重试、文书草稿与报告下载接口。Vue 新增法律场景入口、合同审查、合规检查、文书生成、维权规划与报告页；风险色彩只辅助阅读，文字状态始终可见。

## 验收

测试覆盖条款切分、四类合同风险、合规结果、模板必填字段、路径选择、证据不足、用户隔离、任务状态、API 契约及 PDF 字节输出。后端全量 pytest 和前端生产构建必须通过。真实 LLM 端到端结果仅在有效运行时密钥和人工核验样本存在时单独报告。
