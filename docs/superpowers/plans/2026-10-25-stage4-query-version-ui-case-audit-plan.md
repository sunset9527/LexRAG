# Stage 4 剩余闭环实施计划

1. 为版本链服务补充“按日期选择可查询 collection”的只读解析：从经核验合并来源确定版本、溯源字段和隔离 collection 名；历史 collection 缺失时明确失败，不回退到当前版本。
2. 为现有 2012 治安管理处罚法历史版本构建隔离 collection，但不改变当前知识库指针；为该能力写原子性测试。
3. 扩展 `/query` 的 `case_date`，把选定 collection、版本假设和五项溯源字段注入响应。缓存键加入日期/版本，避免跨日期复用答案。
4. 在前端问题输入区加入可选案件日期，并在引用侧栏展示“适用版本”卡片与 API 返回的只读版本时间线。
5. 在案例服务序列化层计算案号、法院、裁判日期、裁判要旨的 `missing_fields` 和 `metadata_complete`，由案例 API 与页面展示。
6. 每个行为先新增失败测试，再实现最小代码；最后执行后端回归、前端测试/类型检查、Ruff，并更新阶段 4 状态记录。
