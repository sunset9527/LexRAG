# Stage 4 补充实施计划

1. 扩展来源目录：登记宪法 2018、治安管理处罚法 2012/2025，并将 2025 版本设为待核验的现行候选。
2. 新增刑法显式补丁清单和合并服务：只替换清单明确列出的条文，生成带双来源哈希的 `PENDING_REVIEW` 合并候选。
3. 为合并候选增加审核流：未审核不能进入版本链索引；审核后可作为 `consolidated_source_import_id`。
4. 导入并人工确认宪法与治安管理处罚法原件，建立三部法律版本链。
5. 对刑法合并候选、宪法和治安管理处罚法逐库构建隔离索引，读回核验后原子切换。
6. 运行来源分类、合并安全、版本链、重建与 API 聚焦回归，更新阶段记录。
