# 评测方法与证据边界

LexRAG 将工程回归、检索评测和法律回答效果分开报告，三者不可互相替代。

| 层级 | 能回答的问题 | 当前证据 | 不代表什么 |
| --- | --- | --- | --- |
| 工程门禁 | 改动是否破坏既定协议与行为 | Ruff、pytest、Node/Vitest、构建报告 | 不代表法律结论正确 |
| 检索评测 | 标注法条是否被召回 | 固定 JSONL、Recall@K/MRR/NDCG 报告 | 不代表回答适用完整事实 |
| 回答效果 | 回答中的断言是否充分受证据支持 | 需人工标注、Judge 校准和真实模型运行 | 当前统一留在 Stage 8 |

每份正式报告必须记录代码提交、环境、数据版本、命令、样本数、失败样本和已知边界。不得拼接不同提交的最好指标，不得通过删除难题、修改标签或数据凑出结果。

普通 PR 与本地质量门禁不调用真实 LLM 或下载本地嵌入模型；真实模型、浏览器端到端、性能、安全攻击和恢复演练统一由 Stage 8 执行。
